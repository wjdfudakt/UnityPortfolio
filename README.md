3D 사격장
플레이어가 사격장을 자유롭게 이동하며 네 가지 조준 훈련 모드를 선택하는 1인칭 싱글 플레이 게임입니다. 입장 발판에서 일정 시간 머무르면 해당 모드가 시작되며, 결과를 확인한 뒤 재도전하거나 다른 구역으로 이동할 수 있습니다.


항목	내용
프로젝트명	3D 사격장
장르	1인칭 조준 훈련
플레이 방식	싱글 플레이
제출 플랫폼	Windows PC

기획 의도
정확한 사격, 빠른 타겟 전환, 출현 후 반응, 지속적인 추적을 각각 다른 모드로 경험하도록 구성했습니다. 모드별 목표와 종료 조건을 구분하고, 결과 화면에서 다음 라운드 진행·재도전·퇴장을 선택할 수 있도록 했습니다.

조작 방법
입력	기능
W, A, S, D	자유 이동 상태에서 전후좌우 이동
마우스 이동	좌우·상하 시점 회전
마우스 왼쪽 버튼	라운드·타임어택·반응속도 모드 사격

사격과 트래킹은 화면 중앙의 고정 조준점을 기준으로 판정합니다. 모드 진행 중에는 이동이 제한되고 시점 회전만 가능합니다. 트래킹은 클릭 없이 조준점으로 타겟을 따라갑니다.
플레이 흐름
1. 시작: 시작 메뉴에서 Play를 선택합니다.
2. 탐색: 사격장을 이동하며 모드 구역을 선택합니다.
3. 입장: 입장 영역 안에서 연속 2초를 유지합니다. 중간에 벗어나면 대기 시간이 초기화됩니다.
4. 진행: 지정된 플레이 위치로 이동하고 해당 모드를 시작합니다.
5. 결과: 성공·실패 또는 측정 완료 시 결과창을 표시합니다.
6. 다음 행동: 계속 진행하거나 재도전하고, Cancel로 구역을 나갈 수 있습니다.
상태	이동	시점 회전	주요 행동
자유 이동·입장 대기	가능	가능	구역 탐색, 입장 대기 또는 이탈
모드 진행	불가	가능	사격 또는 추적
일시정지	불가	불가	Resume, Exit Mode, Main Menu
결과 확인	불가	불가	Continue 또는 Retry, Cancel


재도전과 다음 라운드 진행은 씬을 다시 불러오지 않고 현재 씬에서 처리합니다. Cancel은 타겟과 진행 정보를 정리하고 입장 영역 바깥으로 이동시켜 자유 이동 상태를 복구합니다.

아래 수치는 기획 기본값입니다. 제출 프로젝트의 Inspector 설정이 다른 경우 실제 적용값에 맞춰 수정해야 합니다.
라운드 모드
제한 시간 안에 목표 점수를 달성하는 모드입니다. 라운드가 올라가면 타겟 종류가 늘어나고 생성 간격이 짧아집니다.
항목	규칙
제한 시간	라운드당 60초
클리어	목표 점수 도달 시 즉시 클리어
실패	시간 초과 또는 한 라운드에서 금지 타겟 3회 명중
목표 점수	100 + (라운드 - 1) × 50
생성 간격	max(0.30, 1.00 - (라운드 - 1) × 0.05)초
동시 타겟 수	최대 5개, 그중 금지 타겟 최대 2개
타겟 유지 시간	기본 4초

1	정지	100	1.00초
2	정지·이동	150	0.95초
3	정지·이동·금지	200	0.90초

- 정지 타겟: 생성 위치에 머무르며 명중 시 설정된 점수를 지급합니다.
- 이동 타겟: 좌우 또는 위아래 방향으로 왕복합니다. 시작 위치와 첫 이동 방향을 무작위로 정합니다.
- 금지 타겟: X 표시로 구분합니다. 명중하면 감점과 금지 타겟 명중 횟수를 함께 적용합니다. 점수는 0 미만으로 내려가지 않습니다.
타겟별 가점·감점은 프리팹 설정값을 사용합니다. 클리어 후 Continue는 다음 라운드, 실패 후 Retry는 같은 라운드를 시작합니다. 점수·발사·명중 통계는 매 라운드 초기화하며, 구역을 나갔다가 다시 입장하면 1라운드부터 시작합니다.
타임어택 모드
60초 동안 정지 타겟을 최대한 많이 명중하는 모드입니다.
- 타겟은 한 번에 하나만 유지합니다.
- 명중하면 다음 타겟을 즉시 생성합니다.
- 가능한 경우 직전에 사용한 스폰 위치는 제외합니다.
- 타겟은 명중할 때까지 유지됩니다.
- 타겟 하나를 명중할 때마다 명중 수가 1 증가합니다.
- 시간이 끝나면 명중 수·발사 수·정확도·최고 명중 수를 표시합니다.
목표 점수에 따른 실패는 없으며, Continue를 선택하면 새 측정을 시작합니다.
반응속도 모드
타겟 출현부터 명중까지 걸린 시간을 측정하는 모드입니다. 1~3초의 무작위 대기 후 중앙에 타겟을 표시하고, 정상 명중 10회를 완료하면 결과를 보여줍니다.
상황	처리
타겟 출현 전 클릭	Too Early 표시, 조기 클릭 수 증가, 같은 시도 다시 대기
출현 후 빗나감	타겟 유지, 명중할 때까지 시간 측정
정상 명중	측정값 표시 후 다음 시도 준비
10회 완료	평균·최단 반응 시간, 완료 횟수, 조기 클릭 수, 최고 평균 표시
일시정지 후 재개	완료 기록 유지, 진행 중이던 시도는 새 대기부터 시작


조기 클릭은 정상 시도 횟수와 발사 통계에 포함하지 않습니다. 타겟이 생성된 프레임의 입력도 제외합니다. 반응 시간의 단위는 ms이며, 빗나간 뒤 명중하기까지의 시간도 포함하므로 시각 반응과 조준 수행을 함께 측정합니다.
트래킹 모드
움직이는 타겟 위에 중앙 조준점을 유지하는 생존형 모드입니다. 라운드와 전체 제한 시간은 없으며, 시간이 지날수록 타겟이 빨라집니다.
항목	기본값
시작 속도	2유닛/초
가속도	0.1유닛/초²
실패까지의 여유 시간	3초
여유 시간 회복 조건	타겟을 0.5초 연속 추적
이동	범위 중앙에서 대각선으로 출발하고 경계에서 반사


속도는 2 + 0.1 × 플레이 시간으로 증가합니다. 타겟을 놓쳤거나 회복 조건을 채우는 중에도 가속은 계속되며, 일시정지 중에는 멈춥니다.
추적 상태	실패 여유 시간 처리
타겟 이탈	남은 시간 감소, 연속 추적 시간 초기화
재추적 중 0.5초 미만	감소만 정지, 아직 회복되지 않음
0.5초 연속 추적 성공	남은 시간을 3초로 초기화
회복 전에 다시 이탈	이전에 남아 있던 시간부터 감소
남은 시간 0초	실패와 결과 표시


예를 들어 2초 이탈하면 1초가 남습니다. 이후 0.5초만 따라갔다가 다시 놓치면 남은 1초부터 감소합니다. 다시 타겟을 잡은 뒤 새로 0.5초를 연속 유지해야 3초로 회복됩니다. 회복해도 생존 시간과 속도는 초기화되지 않습니다.

결과에는 생존 시간·누적 추적 시간·추적 비율·최종 속도·실패 판정용 이탈 시간을 표시합니다. 실패 판정용 이탈 시간은 회복 시 초기화되며, 전체 플레이 동안 놓친 시간의 총합은 아닙니다. Retry는 초기 속도부터 다시 시작합니다. 트래킹 최고 기록 저장은 현재 구현 범위에 포함하지 않습니다.
화면과 피드백
- 왼쪽 HUD에 현재 모드와 점수·진행 상태를 표시합니다.
- 오른쪽 HUD에 남은 시간 또는 트래킹 실패 여유 시간을 표시합니다.
- 입장 영역 안에서는 모드명과 시작까지 남은 대기 시간을 표시합니다.
- 일반 타겟 명중은 초록색, 금지 타겟 명중은 빨간색 히트마커로 구분합니다.
- 발사·일반 명중·금지 타겟 명중 효과음을 재생합니다.
- 일시정지와 결과 화면에서는 커서를 표시하고 이동·시점 입력을 제한합니다.

입장과 상태 전환
구현: 구역 내부에서 일정 시간 머무르면 해당 모드를 시작합니다.

목적: 자유 이동 공간에서 원하는 훈련을 선택하고, 결과 확인 후 다른 구역으로 이동할 수 있도록 합니다.

방식: ModeEntrance.Update()가 플레이어 중심을 영역의 로컬 좌표로 변환하고 Bounds 내부 여부를 검사합니다. 체류 시간이 충족되면 GameManager.TryEnterZone()으로 입장하고, BeginAttempt()에서 상태와 통계를 초기화합니다. 종료는 CancelMode(), 재진행은 ContinueMode()로 처리합니다.

게임 내 결과: 입장 시 지정된 위치로 이동하고 이동이 제한됩니다. 퇴장하면 구역 밖으로 이동하고 자유 이동이 복구됩니다.
타겟 생성과 사격
구현: 스폰 포인트 배열과 활성 타겟 관리 정보를 사용해 타겟을 생성하고, 중앙 조준점으로 명중을 판정합니다.

목적: 생성 수와 금지 타겟 수를 제한하고 현재 플레이 중인 구역에만 사격 결과를 반영합니다.

방식: TargetSpawner가 구역별 스폰을 관리합니다. PlayerShooting.Shoot()는 화면 중앙에서 Raycast를 수행하고 현재 스포너가 소유한 타겟인지 확인합니다. 명중 결과는 점수·통계·효과음·히트마커로 연결됩니다.

게임 내 결과: 타겟 종류에 따라 점수와 피드백이 달라지며, 다른 구역의 타겟은 현재 모드의 명중으로 처리하지 않습니다.
반응속도와 트래킹
구현: 반응속도는 대기·출현·피드백·완료 상태를 구분하고, 트래킹은 생존·추적·이탈·연속 유지 시간을 각각 관리합니다.

목적: 조기 클릭을 정상 반응과 구분하고, 짧게 타겟을 스치는 행동만으로 트래킹 실패 시간을 회복하지 못하도록 합니다.

방식: GameManager.TryBeginShot()과 OnReactionTargetHit()가 반응속도 입력과 측정을 처리합니다. UpdateTracking()은 타겟 이동, 중앙 Raycast, 가속, 이탈 누적, 연속 추적 회복을 처리합니다.

게임 내 결과: 반응속도는 완료 횟수와 평균·최단 시간을, 트래킹은 생존 시간과 추적 비율을 결과창에 표시합니다.
